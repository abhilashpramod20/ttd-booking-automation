STEP 9: PAGE NAVIGATION
═════════════════════════════════════════════════════════════════════════════════
   ① Script monitors URL for change (10 second timeout)
      ↓
   ✓ URL changed? (Page navigated to booking form) → SUCCESS! Go to Step 10
      ↓
   ✗ URL didn't change after 10 seconds?
      ↓
      ⚠️  PROMPT user with options:
      
      "Continue button was clicked but page didn't navigate.
       
       Options:
       - Type 'wait' to wait 10 more seconds
       - Type 'manual' to manually navigate to next step
       - Type 'proceed' to continue without navigation"
      
      Option A: User types 'wait'
      ↓
      → Wait 10 more seconds for navigation
      ↓
      ✓ Navigation happened? → Go to Step 10
         ✗ Still no navigation? → Keep browser open for manual completion
      
      Option B: User types 'manual'
      ↓
      ⚠️  PAUSE - Show recovery prompt
      "Please manually navigate to the next step in the browser"
      ↓
      ⏸️  User navigates manually
      ↓
      User presses ENTER
      ↓
      → CONTINUE TO STEP 10
      
      Option C: User types 'proceed'
      ↓
      → Continue anyway (page may have loaded without URL change)
      ↓
      → CONTINUE TO STEP 10

╔════════════════════════════════════════════════════════════════════════════════╗
║                             KEY PRINCIPLES                                    ║
╚════════════════════════════════════════════════════════════════════════════════╝

✓ FAIL ONCE → OFFER RECOVERY
  When any step fails, don't retry automatically. Show recovery immediately.

✓ NO TIMEOUT ON PAUSES
  User can take as long as needed to complete manual action.

✓ NEVER SKIP STEPS
  Every step is important. Manual recovery ensures sequence integrity.

✓ CLEAR INSTRUCTIONS
  Each recovery prompt explains exactly what user should do.

✓ CONTINUE TO NEXT STEP
  After manual recovery, automation continues to the next step (not start over).

✓ FULL VISIBILITY
  Screenshots and logs show everything that happened.

╔════════════════════════════════════════════════════════════════════════════════╗
║                            HOW TO USE                                         ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. Start the script:
   $ npm run full-flow

2. When any step fails, you'll see a clear prompt

3. Complete the action in the browser

4. Press ENTER to continue

5. Script automatically moves to the next step

6. If another step fails, repeat 2-5

7. When automation is done, complete remaining steps manually

8. Press ENTER when you're done → Script exits
