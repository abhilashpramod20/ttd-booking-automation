THE COMPLETE AUTOMATION FLOW
═════════════════════════════════════════════════════════════════════════════════

🚀 START HERE:
   $ npm run full-flow

⏱️  WHAT HAPPENS (Automatically):
   
   1. Script navigates to TTD website
   2. Script enters your username & password
   3. Script solves CAPTCHA (automatic + manual fallback if needed)
   4. Script logs in
   5. Script waits for donation form page
   6. Script enters ₹30,000 donation amount
   7. Script checks "Indian Citizenship" checkbox ✓
   8. Script checks "Corpus Donation" checkbox ✓
   9. Script clicks "Continue" button
   10. Script monitors page for navigation (up to 10 seconds)

⏸️  CHECKPOINT - AUTOMATION COMPLETE:
   
   Terminal displays:
   ✅ AUTOMATION CHECKPOINT - ALL AUTOMATED STEPS COMPLETED
   
   Browser shows:
   - Current page (might be booking form or intermediate page)
   - You're logged in and authenticated
   
   Next action:
   - Look for "Current Booking" button OR
   - Look for booking form fields (date, pilgrim info)

📋 MANUAL COMPLETION (You do this):
   
   Step 1: Click "Current Booking" (if visible)
   Step 2: Select darshan date on calendar
   Step 3: Select time slot
   Step 4: Fill pilgrim details:
           - Full name
           - Age
           - Gender
           - Mobile number
           - Email
           - Address (if required)
   Step 5: Review booking summary
   Step 6: Click "Proceed to Payment"
   Step 7: Select payment method
   Step 8: Enter payment details
   Step 9: Complete transaction
   Step 10: Note booking confirmation number

✅ FINAL STEP:
   
   When complete:
   → Return to terminal
   → Press ENTER
   → Script exits
   → Browser closes

TROUBLESHOOTING QUICK TIPS
═════════════════════════════════════════════════════════════════════════════════

Issue: Page navigation prompt appears
→ Type: "wait" and press ENTER
→ This waits 10 more seconds for page to load

Issue: Can't find Current Booking button
→ You might be on booking form already
→ Look for date picker or form fields
→ Start filling in the details

Issue: Payment gateway fails
→ Check internet connection
→ Try different payment method
→ Retry transaction

Issue: Browser window closes
→ Run script again: npm run full-flow
→ Complete the entire flow again

Issue: Can't find available dates
→ Try different month
→ Try weekday instead of weekend
→ Check TTD website for availability
